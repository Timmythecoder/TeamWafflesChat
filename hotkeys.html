App Protocols & Web Links:

  • Desktop Apps (e.g., onenote:): These can be blocked by your browser for security. If they don't work, there is often no fix.
    • OneNote Specific Page: In the OneNote desktop app, right-click a page > "Copy Link to Page". Paste the link here.
    • Other apps: spotify:, ms-calculator:
  • Web App Fallbacks (More Reliable): If desktop app links fail, use a web link instead. These open the web version of the app.
    Word: https://www.office.com/launch/word
    Excel: https://www.office.com/launch/excel
    PowerPoint: https://www.office.com/launch/powerpoint

Important: Launching desktop apps from a website is often disabled by browsers or school network policies. Using a standard web URL (like `https://google.com` or the Office links above) is the most reliable option.
